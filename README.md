# Sistema Automatizado de Control de Acceso y Cobro de Vehículos (LPR)

Proyecto académico desarrollado para la materia **Dirección de Proyectos Informáticos**.

## Descripción

El sistema permite automatizar el ingreso, egreso y cobro de vehículos dentro de un estacionamiento mediante tecnología de reconocimiento de patentes (LPR - License Plate Recognition).

La solución busca reemplazar procesos manuales para mejorar:

- eficiencia operativa
- velocidad de atención
- control de ingresos
- trazabilidad de vehículos
- experiencia del cliente

---

# Objetivos del Proyecto

- Automatizar el control de acceso vehicular
- Reducir errores manuales
- Mejorar tiempos de operación
- Implementar una marcha blanca controlada
- Validar la operación antes del reemplazo definitivo


# Funcionalidades Principales

## 1. Ingreso de Vehículos

- Captura automática de patente
- Validación de formato
- Registro automático de hora de ingreso
- Validación de duplicados

---

## 2. Salida y Cobro

- Cálculo automático de estadía
- Tolerancia configurable
- Selección de medio de pago
- Emisión de ticket

---

## 3. Administración

- Gestión de usuarios
- Gestión de abonados
- Configuración de tarifas
- Reportes e incidentes

---
