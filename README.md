# Sistema de Estacionamiento LPR
Proyecto de Dirección de Proyectos Informáticos.

## Descripción
Sistema automatizado de control de acceso y cobro de vehículos mediante reconocimiento de patentes (LPR).

## Objetivo
Eliminar procesos manuales, mejorar la eficiencia operativa y reducir errores en el estacionamiento.

## Funcionalidades
- Registro automático de ingreso y egreso
- Cálculo de estadía
- Generación de ticket
- Interfaz para cajeros
- Marcha blanca y validación en entorno real

##  Equipo
- Project Manager
- Analista de Negocio
- Arquitecto de Infraestructura
- Arquitecto de Datos
- Front-End / Capacitador
- QA

## Metodología
- Enfoque predictivo (gestión)
- Desarrollo incremental (MVP)
